# Skills Library

These Skills are meant to be shared, improved and added to.  Any skill you think might be useful to someone else wether for planning, development or workflow effeciency, please add it here.

Until there are more skills, everything can live at the top level.

To learn more about skills, see `./OVERVIEW.md`

## Current Skills of note:

- [`sentry-issue`](./sentry-issue/SKILL.md): This skill uses the Sentry MCP server to read a sentry issue, evaludate root cause and propose solutions.

- [`pr-review`](./pr-review/SKILL.md): This skill instructs Claude to read the PR Review comments left by Copilot in github, evaluate their validity and propose solutions.  Requires a PR (duh) and a completed PR review by Copilot.
